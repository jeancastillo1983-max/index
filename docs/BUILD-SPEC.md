# Fall Protection Competent Person — Build Spec (single source of truth)

This file is the contract every builder follows. Content lives in `fall-protection-cp/content/*.js`.
The HTML5 player, the storyboard (.docx), the facilitator deck (.pptx), job aids (PDF) and the
SCORM 1.2 package are all generated from that same content. Change content once; rebuild everything.

Source document: "Fall Protection Competent Person Course: Outline and Strategy" (JC, Nov 25 2026).
Decisions: foremen & lead hands only; federal OSHA only; scaffold/ladder CP courses separate;
SCORM 1.2; field sign-off by safety manager; Upchurch branding (logo + black/blue/green, applied Nov 26).

## 2. Content registration (plain JS, works from file://, an LMS, and Node)

```js
// content/m5.js
COURSE.addModule({
  id: 'm5', num: 5, title: 'Anchors, connectors and clearance', minutes: 45,
  build: 'Storyline',                       // storyboard "Main build" column
  tagline: 'Tied off is not the same as protected.',
  hero: 'img_m5_hero',                      // MEDIA id (optional; engine falls back to art)
  objectives: ['Select anchorages that …', '…'],
  citations: ['1926.502(d)(15)', '1926.502(d)(16)', 'ANSI/ASSP Z359.6', …],
  jobAids: [{ title: 'Pocket clearance card', file: 'jobaids/pocket-clearance-card.html',
              pdf: 'jobaids/pdf/pocket-clearance-card.pdf', desc: '…' }],
  lessons: [
    { id: 'm5-l1', title: 'What makes an anchor', minutes: 10, blocks: [ /* blocks */ ] },
    …
  ],
  kc: { title: 'Knowledge check', questions: [ /* 3–5 MCQ objects, see §5 */ ] }  // modules 1–8
});
```

Ids: module `mN`; lesson `mN-lK`; interactive blocks need an `id` unique in the course (`m5-clear-dee`).
Strings may contain light inline HTML: `<b> <em> <br> <cite> <span class="hl">`.
`<cite>1926.502(d)(16)</cite>` renders as a citation "receipt" chip. Never put raw regulation text on screen.
Paragraph arrays: any `body` may be a string or an array of strings (one paragraph each).

### Fields every block may carry
| field | meaning |
|---|---|
| `type` | block type (§4) — required |
| `id` | required for any block that tracks completion (all interactions) |
| `narration` | voice-over script (peer voice). Read by TTS with captions; printed in the storyboard |
| `required` | `true` = learner must finish it before the next `continue` gate opens (interactions default true) |
| `sb` | storyboard-only notes: `{ visual, search, build, notes }` — `search` = Articulate Content Library search term, `build` = Storyline/Rise build note (variables, triggers, layers) |

## 3. Runtime API (js/core.js — already written; read it)

`window.FP`:
- `FP.register(type, render)` — `render(block, ctx) → HTMLElement`
- `FP.h(tag, attrs, ...children)` — element builder (`class`, `html`, `on:{click}`, `style`, data-*, aria-*)
- `FP.media(id)` → MEDIA entry or `null` (never throw on a missing id: render nothing / placeholder art)
- `FP.char(id)` → character object from COURSE.characters
- `FP.avatar(id, size)` → SVG element (implemented in art.js by builder A)
- `FP.shuffle(arr)`, `FP.uid()`, `FP.strip(html)`, `FP.esc(text)`
- `FP.speak(text)` / `FP.stopSpeaking()` — implemented by engine (TTS + caption bar)
- `ctx` passed to renderers: `{ module, lesson, block, complete(result), isComplete(), save(obj), load() }`
  - `complete(result)` marks the block done (opens `continue` gates, counts toward lesson completion)
  - `save/load` persist small per-block UI state (localStorage only; NOT SCORM suspend_data)

Script order in index.html: tokens.css, core.css, interactions.css → config.js, core.js, scorm.js, art.js,
blocks-core.js, blocks-interactions.js, exam.js, content/course.js, content/media.js, content/scenes.js,
content/m0.js…m9.js, content/exam.js, engine.js (engine boots on DOMContentLoaded).

## 5. Knowledge checks and the exam

MCQ object: `{ id?, question, multi?, options:[{text, correct, fb?}], explain, cite }`.

`content/exam.js`:
```js
COURSE.setExam({
  rules: { pass: 0.8, attempts: 3, criticalRequired: true, count: 40 },
  slots: [  // 40 slots, blueprint below; each slot has a pool of 3 interchangeable questions
    { id: 'x01', area: 'm2', critical: true, tag: 'stop work', pool: [Q, Q, Q] }, …
  ]
});
```
Question formats: `mc` (single), `multi` (select all), `numeric` (`answer`, `tolerance`, `unit`),
`sequence` (`items` in correct order), `hotspot` (`scene`, `correct:[hazardIds]`, select all that apply).
Every question: `{ type, stem, …, explain, cite, module }`. Feedback after submit names the right answer,
the reason and the citation. Scenario-style stems (Riverside, characters) for ≥70 % of slots.

Blueprint (questions / scenario / critical): M2 4/2/1 (stop work) · M3 6/5/0 · M4 7/6/2 (system selection)
· M5 7/5/2 (anchor strength, clearance) · M6 6/4/1 (removal from service) · M7 4/3/1 (rescue plan)
· M8 6/3/1 (stop work under pressure). Total 40 / 28 / 8.

Rules: pass = 80 % (32/40) AND all 8 critical correct. 3 attempts. After a failed attempt the modules tied
to missed items are flagged "review required" and must be revisited before the next attempt.
Pass → SCORM `passed`, score.raw, certificate. SCORM suspend_data stays under 3,500 chars.

Certificate wording (verbatim): "Fall Protection Competent Person: Knowledge Component Complete. This certificate
confirms completion of online training only. The holder is not designated as a competent person until the
employer's field verification is signed and the employer grants authority to take prompt corrective measures
under 29 CFR 1926.32(f)."

Field verification items (8, safety manager marks observed / pass / redo, date, signature):
1 Walks an active work area and identifies existing and predictable fall hazards · 2 Selects a compliant system for
two real tasks and explains why · 3 Inspects a harness, lanyard or SRL, and an anchor, and correctly tags one item ·
4 Calculates fall clearance for an actual tie-off point · 5 Inspects a guardrail run and a hole cover against spec ·
6 Walks through the site rescue plan and confirms equipment is on hand · 7 Demonstrates a stop-work conversation
(role-play with the safety manager is acceptable) · 8 Reviews a worker training certification record for completeness.

## 6. Story world (keep consistent everywhere)

**Riverside Medical Office** (fictional): 4-story structural steel frame, composite metal deck with
concrete slabs, low-slope TPO roof 180 ft × 96 ft (wider than 50 ft), parapet 24 in on the east side
only, two skylights over the atrium, one elevator shaft, two stair openings, floor-to-floor 14 ft.
The GC self-performs concrete. Schedule is 2 weeks behind after a steel delivery slip; the owner
(a regional health system) wants turnover before flu season. Daily rhythm: 6:30 a.m. huddle.

Characters (fictional composites — avatars are illustrated, built in art.js):
| id | name | role | voice & arc |
|---|---|---|---|
| `ray` | Ray | Foreman, 28 years in | Knows everything, cuts corners he has "earned". Normalization-of-risk voice. His deck-edge shortcut has "worked a hundred times". Comes around in M8 after his own near miss. White hard hat, gray beard. |
| `tasha` | Tasha | Lead hand, newly designated competent person (11 yrs in) | Learner's stand-in. Makes calls, gets pushback, sometimes gets it wrong. Default narrator voice ("I"). White hard hat with orange CP sticker. |
| `dee` | Dee | Second-year apprentice | Watches what the crew does, not what the rules say. The person the learner protects. Green hard hat (new-hand color). |
| `marco` | Marco | Superintendent | Not a villain. Schedule, owner and money pressure. Responds to the right argument (schedule risk of a fall, cost, owner requirements). White hat, collared shirt, vest. |
| `luis` | Luis | Survivor (M1 only) | Fell years ago on another job, tied off with a 6 ft lanyard to a foot-level anchor on a 12 ft mezzanine; hit the slab anyway. Broken pelvis and both heels. Tells it in his own words. Never graphic. |
| `narrator` | Crew narrator | — | Plain, peer voice. Use only when no character fits. |
| `safety` | Safety manager | Signs the field verification | Brief appearances. |

**The "100 times" thread (Ray's shortcut)**: Ray steps outside the perimeter cable rail at the Level 3
deck edge to guide crane-landed bundles of rebar/deck sheets by hand. M1: thread begins ("done it a
hundred times"). M3: visible in the deck scene. M4: Ray wants to pull the rail and use a safety monitor
on the deck (not legal: monitoring alone is only for roofing on low-slope roofs ≤ 50 ft wide, or as part of
a written fall protection plan). M5: he clips to the guardrail cable (not an anchor). M6: "That harness is
fine, it's my lucky one." M8: the shortcut fails — a rail post was pulled for a delivery, the cable sags,
Ray catches the column; near miss, nobody hurt. Learners see what Tasha could have said in M1.

**Tone**: peer voice, not compliance voice. Decide first, then learn (most lessons open with a choice the
learner may get wrong). Citations are receipts in feedback, not headlines. Every risk is paired with a
doable action. No gore, no graphic injury images, no scare stats without an action. ≤60 words per block body
where possible; short sentences; readable on a phone in a truck. Respect experience ("You probably
already know this" test-outs). Every module ends with something usable Monday (job aid, checklist, script).

## 7. Technical facts (use these numbers; verify statistics with WebSearch before using any new one)

- Competent person 1926.32(f): capable of identifying existing **and predictable** hazards AND has
  **authorization to take prompt corrective measures**. Qualified person 1926.32(m): degree/certificate/
  professional standing or extensive knowledge, training and experience; can solve problems. ANSI/ASSP Z359.2
  roles: authorized person (user), competent person, qualified person, program administrator, competent rescuer.
- Trigger height: 6 ft in construction (1926.501(b)(1)). Hole = gap ≥ 2 in least dimension; opening (wall) =
  ≥ 30 in high and ≥ 18 in wide (1926.500(b)). Low-slope roof ≤ 4:12; steep roof > 4:12.
- Guardrails 1926.502(b): top rail 42 in ± 3 in; withstand 200 lb outward/downward within 2 in of top edge;
  under 200 lb not below 39 in; midrail midway when no wall ≥ 21 in; midrails 150 lb; ≥ ¼ in nominal; no
  steel/plastic banding as rails; wire rope top rail flagged at ≤ 6 ft intervals. Toeboards ≥ 3½ in, 50 lb (502(j)).
- Covers 1926.502(i): support 2× the weight of workers, equipment and materials; secured against
  displacement; color-coded or marked "HOLE" or "COVER"; roadway covers 2× max axle load.
- Safety nets 1926.502(c): as close as practicable under the surface, never more than 30 ft below; inspected weekly.
- PFAS 1926.502(d): anchorage 5,000 lb per employee attached, or designed/installed/used under a qualified
  person with safety factor ≥ 2 [(d)(15)]; max arresting force 1,800 lb with harness; free fall ≤ 6 ft and no
  contact with lower level; deceleration ≤ 3.5 ft [(d)(16)]; lanyards & vertical lifelines 5,000 lb [(d)(9)];
  D-rings & snaphooks 5,000 lb, proof-tested 3,600 lb; locking snaphooks only; no snaphook to webbing, to each
  other, to a loaded D-ring, to a horizontal lifeline unless designed for it; components that arrested a fall:
  remove from service until a competent person determines undamaged [(d)(19)]; prompt rescue [(d)(20)];
  inspect before each use [(d)(21)]; never attach to guardrails or hoists [(d)(23)]; body belts not allowed in PFAS.
  Horizontal lifelines: designed by a qualified person, SF ≥ 2 [(d)(8)].
- Positioning 1926.502(e): free fall ≤ 2 ft; anchorage 2× impact load or 3,000 lb, whichever greater.
- Warning lines 1926.502(f): ≥ 6 ft from edge; rope 34–39 in high, flagged ≤ 6 ft; (mechanical equipment
  rules: 6 ft parallel / 10 ft perpendicular). Controlled access zones 1926.502(g). Safety monitoring 1926.502(h):
  a competent person, same surface, within sight and voice, no other duties. 1926.501(b)(10): low-slope roofing
  — monitoring alone only on roofs ≤ 50 ft wide. Fall protection plan 1926.502(k): only leading edge, precast,
  residential; written by a qualified person, site-specific, kept on site, implemented under a competent person.
- Holes 1926.501(b)(4) incl. skylights; wall openings (b)(14) when bottom edge < 39 in above the surface
  and outside bottom edge ≥ 6 ft above lower level; steep roofs (b)(11) guardrail + toeboard, net or PFAS.
- Scope 1926.500(a): scaffolds → Subpart L, steel erection → Subpart R, stairways & ladders → Subpart X.
- Training 1926.503: trained by a competent person; written certification record with name, date(s),
  signature of trainer or employer; retrain when workplace changes, system/equipment changes, or the worker
  shows inadequate knowledge or use.
- Suspension: OSHA SHIB 03-24-2004 (orthostatic intolerance can kill within minutes). Plan to reach a
  suspended worker in minutes (common program targets: contact in ~6 min, down in ~15). 911 is not a plan.
- Z359 references: Z359.2 managed program; Z359.4 assisted rescue/self-rescue; Z359.6 active system design;
  Z359.11 harnesses; Z359.12 connectors; Z359.13 energy-absorbing lanyards; Z359.14 SRDs (incl. SRL-LE
  for leading edges); A10.32 construction PFAS. Course design aligned to Z490.1.

**Clearance formula (all builders use exactly this)** — distances in feet, measured below the walking surface:
```
A  = anchor height above the walking surface (0 = foot level, 5 ≈ D-ring height, 7 = overhead beam)
L  = lanyard length (6)      DD = deceleration distance (3.5 max)    HS = harness stretch / D-ring shift (1)
H  = D-ring height above the worker's feet (5)                       SM = safety margin (2)
Free fall (lanyard)        FF = max(0, L + H − A)              must be ≤ 6
Lowest point of feet       F  = L + DD + HS + H − A            (lanyard)
                           F  = FFsrl + DD + HS                (overhead SRL, FFsrl ≤ 2, DD ≤ 3.5 → use 2 + 3.5)
Required clearance         RC = F + SM        Hits if RC > available clearance
```
Canonical Dee case: 6 ft lanyard to a foot-level anchor (A=0) on the Level 3 deck edge, 14 ft to the slab
below: FF = 11 ft (violates 6 ft), F = 15.5, RC = 17.5 > 14 → she hits. Fix 1: overhead beam anchor A = 7 →
FF 4, F 8.5, RC 10.5 ✔. Fix 2: overhead SRL → F 6.5, RC 8.5 ✔. Luis: 6 ft lanyard, A = 0, 12 ft
mezzanine → F 15.5 > 12 → hit. Swing fall: extra drop = R − √(R² − d²) for line length R and horizontal offset d.
